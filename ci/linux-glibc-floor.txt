# Oldest glibc / libstdc++ the shipped Linux artifacts are promised to load on.
#
# Read by ci/assert-glibc-floor.sh, which every Linux prebuild leg
# (ts-prebuild.yml, java-prebuild.yml, capi-release.yml) runs on the artifact
# it is about to upload. A build that starts importing a newer symbol version
# fails there, instead of shipping a library that dies on users' machines with
# "version `GLIBC_2.xx' not found".
#
# The floors come from the build images, not from the runner: both arches
# build inside a pinned container through `cross` (bindings/Cross.toml,
# capi/Cross.toml), so moving the GitHub runner image cannot move them.
#
# x86_64 — ci/cross/x86_64-gnu.Dockerfile (ubuntu:24.04: glibc 2.39, GCC 13).
#   Distros: Ubuntu 24.04+, Debian 13+, Fedora 40+, RHEL 10.
#   It cannot go below 2.38 without building ONNX Runtime from source:
#   ort-sys's prebuilt x86_64 libonnxruntime.a imports __isoc23_strtol & co.,
#   new in glibc 2.38. 2.39 itself comes from Rust std's process spawning
#   (weak pidfd_spawnp / pidfd_getpid references, versioned GLIBC_2.39), which
#   any build against 2.39 headers picks up once Command::spawn is linked in.
#   GLIBCXX_3.4.32 is GCC 13's libstdc++; every distro above ships it or newer.
#   Measured: published 0.2.0 artifacts (built natively on ubuntu-24.04) need
#   GLIBC_2.38 / GLIBCXX_3.4.31; the C API at the commit that introduced this
#   file needs GLIBC_2.39 (pidfd_*) / GLIBCXX_3.4.31.
#
# aarch64 — ci/cross/aarch64-gnu.Dockerfile (ubuntu:22.04 sysroot, glibc 2.35,
#   libstdc++ from GCC 12). ORT's aarch64 prebuilt does not need 2.38.
#   Distros: Ubuntu 22.04+, Debian 12+, RHEL 10.
#   Measured: published 0.2.0 Neon addon and C API need GLIBC_2.35 /
#   GLIBCXX_3.4.30.
#
# Raising a floor drops support for every distro below it: do it on purpose,
# in the same PR that changes the build image, and say so in the release notes.
#
# <rust-target>             <max GLIBC_>  <max GLIBCXX_>
x86_64-unknown-linux-gnu    2.39          3.4.32
aarch64-unknown-linux-gnu   2.35          3.4.30
